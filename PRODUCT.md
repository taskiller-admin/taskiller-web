# Taskiller
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product purpose
An API-first personal task-execution system: capture, structure, plan, execute, review, and learn. Projects hold Sprints and Chores; a Chore is the executable unit. Work Types and Focus Plans help users choose how to work. Execution Sessions use authoritative server timestamps.

## Users and operating context
People organizing their own work, planning a focus session, and learning from its history. Desktop and mobile browsers, with installable PWA support. Source: product README and repository domain specifications.

## Constraints
Preserve the active Django API contract, authentication security, ETag concurrency, idempotency, offline-write rejection, keyboard accessibility and light/dark themes. Never fabricate user activity or productivity metrics.

## Visual brief confirmed by user
The previous UX is improved but visually bland. Overhaul every surface. User approved ink blue, coral focus orbits, crisp typography and dimensional surfaces, and explicitly requested extensive autonomous and reactive motion with smooth state changes. Include visible loading feedback and simple generated avatars. Reduced-motion preferences remain supported.
