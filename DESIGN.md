# Taskiller — Momentum

## Visual system
Ink blue navigation (#152b49), porcelain workspace (#eff3f8), white dimensional surfaces, coral actions (#ff765d), restrained mint (#afe4d4) and lilac (#d1c8f4) accents. Dark mode uses blue-black canvas and layered navy surfaces. Use semantic CSS tokens rather than hard-coded text colors on theme surfaces.

Sora display headings give the product character; Manrope body typography keeps dense work legible. Fonts are self-hosted with OFL licenses. Persistent desktop rail creates a recognizable workspace; mobile uses a translucent bottom navigation and compact header.

## Signature
Concentric focus orbits connect the product's planning and execution loop to its visual identity. Show them in the landing, authentication showcase, workspace focus invitation and session experience, with context-specific scale. Never imply invented statistics.

## Motion
User explicitly requested abundant activity. Use autonomous orbital motion and breathing details, staggered surface entrances, reactive hover/press feedback, loading spinners and shimmer, route progress and state transitions. Motion must communicate state without delaying network completion. Honor reduced motion across all global and local animations. SVG and CSS assets remain native and lightweight.

## Avatar
A deterministic locally generated geometric identity per user id. No third-party avatar requests. Device-local customization is explicitly labeled; do not claim backend synchronization.

## Coverage
Landing; login; register; forgot/reset password; verify email; account deletion; offline/error; Today; Inbox; Projects; work detail/editor; Focus Plan; Execution Session/review; History; Analytics; Settings and all their dialogs and loading/empty/error states.
